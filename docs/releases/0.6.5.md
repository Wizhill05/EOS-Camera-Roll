Add paired photo browsing, capture information, camera-aware ratings and a redesigned filter sheet.

- RAW and JPEG files with the same stem in the same folder appear as one photo, with the JPEG thumbnail. The viewer has fixed RAW/JPEG tabs; Save and Lightroom use the selected original. Unpaired and ambiguous filenames remain separate.
- Import camera stars from small file-information responses. Refresh camera ratings reads beyond visible thumbnails, can be stopped, and continues across bounded batches. Cached thumbnails still load without network revalidation.
- Explicit star changes update both files in a pair when the camera advertises contents PUT. Each file requires matching rating readback before the app labels it saved on the camera. Unsupported, offline or unconfirmed edits remain clearly labelled phone-only, including existing local ratings.
- Show shutter speed, aperture and ISO in the viewer. Information includes additional available EXIF settings. JPEG metadata comes from the original; standalone RAW exposure/lens data comes from the bundled LibRaw reader, without remote header probes.
- Replace the filter alert with a red-accented bottom sheet: RAW, JPEG, paired/unpaired files, saved/not saved, minimum/exact stars, unrated/unknown ratings, camera/phone rating source, ISO bands and camera folder. Capture filters use metadata already read from opened originals.
- Bulk saving from the combined view includes both originals. RAW/JPEG filters save that format, and the viewer saves its selected original. A paired saved mark requires both originals.

Validation: 37 simulated Android workflows, 81 host checks, native dark/light filter and paired-viewer renders, release lint/build and no-playback APK inspection. The public-domain R50 V CR3 sample rendered at 6048×4020 and returned capture settings. The ARM64 native library was rebuilt. Physical R50 V rating writeback and phone UI behavior still require a device check; unsupported camera capability is not reported as successful synchronization.
