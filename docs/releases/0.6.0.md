EOS Camera Roll 0.6.0 introduces a redesigned red-accented gallery and the new app name and logo. Install this APK over the existing Camera Link Lab / Camera roll app to retain settings and ratings.

- Rounded two-column photo gallery with portrait and landscape tile proportions.
- Dark, light and system appearance, with Library / Rated / Saved navigation.
- Folder/rating filters and download actions moved into sheets to reduce clutter.
- Portrait thumbnail orientation falls back to camera/original EXIF when small JPEGs omit it, including Canon CR3 CMT1 metadata. Normalized thumbnails persist between launches.
- Restored library and thumbnail cache after restart. Refresh reconnects without clearing the existing library.
- Distinct messages for device not found, camera out of reach, access/account rejection, partial scans, empty cards and empty filters.
- Existing full-resolution viewing, local ratings, saved marks, original downloads, video playback and Lightroom handoff remain available.
- Bounded thumbnail disk cache and cleanup of interrupted original-preview downloads.

Android 10+, arm64. Package and signing identity are unchanged. Local Android workflow, protocol, orientation and cache checks passed. The redesigned build still needs physical-phone validation. Lightroom manages its own imported files, edits and deletion; the app cannot guarantee Lightroom's storage cleanup.
