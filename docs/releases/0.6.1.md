EOS Camera Roll 0.6.1 includes the new red-accented gallery, app name and camera/film logo introduced in 0.6.0, plus a final thumbnail-cache correction.

- Rounded two-column photo gallery with portrait and landscape proportions, dark/light/system appearance, and floating Library / Rated / Saved navigation.
- Filters and download actions grouped into sheets to reduce clutter.
- Upright portrait thumbnails using camera/original EXIF, including CR3 CMT1 metadata.
- Persistent library and normalized thumbnail cache. Refresh reconnects without clearing cached photos.
- Separate messages for an unreachable camera, missing device address, access/account rejection, partial scans, empty cards and empty filters.
- Original JPEG/RAW viewing, video playback, local ratings, saved marks, folder downloads, card copying and Lightroom handoff remain available.
- Fix: an evicted or changed thumbnail no longer inherits stale orientation from a previous file revision. A regression test reproduces the wrong rotation before the fix and checks corrected pixels afterward.

Install over the existing Camera Link Lab / Camera roll / EOS Camera Roll app. Android 10+, arm64. Package and signing identity are unchanged. Local build/lint, fourteen Android workflow tests and seventy host checks passed. Physical-device testing of this redesign, ARM64 RAW performance and Lightroom import is still pending.
